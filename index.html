BYOVD

Self-protecting driver attestation.

Problem
Attackers load signed vulnerable drivers to reach Ring 0 and blind the EDR watching them.
Approach
A WDM + Minifilter driver intercepts image loads and streams them over \ByovdPort to a C# engine. ObRegisterCallbacks strips termination and VM-write rights from handles to the service.
Result
Sub-millisecond load telemetry; a known-bad driver flagged on the dashboard; Task Manager, taskkill /F, and Process Explorer all denied. Documented in a co-authored IEEE-format paper.
  • C
  • WDM
  • Minifilter
  • C# / .NET
  • SHA-256
  • LOLDrivers

My Onsite

One incident, one answer.

Problem
Four EDR platforms describe the same endpoint differently. Analysts get conflicting alerts and no way to replay the call.
Approach
Deterministic FastAPI + MySQL reconciliation: 10-minute windows, four ordered rules, append-only decision revisions, and a public audit trace. ThreatForge applies the same thesis to fraud and sanctions signals â€” credibility, fusion, explainable risk.

One explainable decision per conflict, replayed from the same event set. Five EDR fixtures pass; the fraud engine held 70 requests at zero errors, ~38 ms median against a 2 s budget.

Al Jazira

A bank assistant with a firewall.

Problem
A bilingual bank assistant has to answer in English and Arabic, stay inside banking, and never let a card number reach the model.
Approach
A FastAPI + LangChain agent with a PII/PCI firewall before inference, a scope classifier, seven tools over masked SQLite data, BM25 retrieval with citations, and an audit log. Provider-swappable across Groq, Qwen, Grok, and Ollama.
Result
Tender-ready POC with EN/AR RTL parity. Sensitive data is stripped before any LLM call; the demo database only ever holds masked numbers.
  • Python
  • FastAPI
  • LangChain
  • SQLite
  • BM25
  • RTL
